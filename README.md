# PhishGuard: Smart Phishing URL Detector

A web app that checks URLs and messages and tells the user if they look safe or suspicious (phishing).

## Live App
https://phisguard-u1s1.onrender.com
(The free server sleeps. The first load can take about 50 seconds.)

## Features
- Home page
- Login and signup
- URL / message scanner
- Scan history
- Dashboard

## Technologies Used
- Python and Flask (backend)
- MySQL (database)
- HTML, CSS and JavaScript (frontend)
- Hosted on Render

## How to Run on Your Computer
1. Install Python.
2. Run: pip install -r requirements.txt
3. Run: python app.py
4. Open http://127.0.0.1:5000 in your browser.

## Project Files
- app.py: main Flask server
- templates/: all HTML pages
- style.css: design
- script.js: page scripts
- requirements.txt: Python packages
